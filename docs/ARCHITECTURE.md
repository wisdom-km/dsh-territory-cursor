# 地盘光标的结构

规则在 `lib/core`。设置页和以后的工具只显示核心给出的状态。`lib/main.js` 是唯一的组装处。

核心文件不引用旁车、光标窗口、Harness 或 React。这条由 `npm test` 里的结构测试卡住。

第 1 步只有未确认状态和设置页。屏幕、窗口、点击、光标留在后面的步骤，再放到端口后面。

| 以后的位置 | 放什么 |
| --- | --- |
| `lib/ports` | 屏幕、窗口树、控件、时钟、键鼠监视 |
| `sidecar` | C# 旁车 |
| `overlay` | 假光标和边框 |
| `lib/dsh` | 两个工具 |
